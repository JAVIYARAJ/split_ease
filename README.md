# SplitEase 💸
A Flutter-based Expense Tracker & Bill Splitting App

SplitEase is a simple and intuitive expense tracking application built with Flutter.  
It helps users track daily expenses, split bills with friends, and manage shared spending — similar to Splitwise.

---

## ✨ Features

- 📊 Track daily & monthly expenses
- 🤝 Split expenses with friends or groups
- 💰 See who owes whom and how much
- 🧾 Add, edit, and delete expenses
- 📈 Clean and user-friendly UI
- 🌙 Light & Dark mode (optional)
- 📱 Cross-platform (Android & iOS)

---

## 🛠 Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Provider / Riverpod / Bloc (choose one)
- **Database:** Firebase / SQLite / Hive
- **Authentication:** Firebase Auth (optional)
- **Backend:** Firebase / REST API (optional)
